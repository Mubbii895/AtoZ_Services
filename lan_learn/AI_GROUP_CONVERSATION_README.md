# AI Group Conversation Feature - ಕನ್ನಡ ಭಾಷಾ ಕಲಿಕೆ ಅಪ್ಲಿಕೇಶನ್

## ವೈಶಿಷ್ಟ್ಯಗಳು (Features)

### 🤖 AI Group Conversation System
ಈ ಹೊಸ AI ವೈಶಿಷ್ಟ್ಯವು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಗುಂಪು ಸಂಭಾಷಣೆಗಳನ್ನು ನಿರ್ವಹಿಸುತ್ತದೆ:

#### ಮುಖ್ಯ ವೈಶಿಷ್ಟ್ಯಗಳು:
- **ಸ್ವಯಂಚಾಲಿತ ಗುಂಪು ಆಯ್ಕೆ**: ಲರ್ನರ್ಸ್ ಪಟ್ಟಿಯಿಂದ ಯಾದೃಚ್ಛಿಕವಾಗಿ 4 ಜನರನ್ನು ಆಯ್ಕೆ ಮಾಡುತ್ತದೆ
- **ರೌಂಡ್ ಆಧಾರಿತ ಸಂಭಾಷಣೆ**: ಪ್ರತಿ ಗುಂಪಿನೊಂದಿಗೆ 4 ಸಂಭಾಷಣೆ ರೌಂಡ್‌ಗಳು
- **ಸ್ವಯಂಚಾಲಿತ ಗುಂಪು ಬದಲಾವಣೆ**: 4 ರೌಂಡ್‌ಗಳ ನಂತರ ಹೊಸ ಗುಂಪು ಆಯ್ಕೆ
- **ಪುನರಾವರ್ತನೆ ತಪ್ಪಿಸುವಿಕೆ**: ಹಳೆಯ ಗುಂಪುಗಳು ಪುನರಾವರ್ತನೆಯಾಗುವುದಿಲ್ಲ
- **ನಿರಂತರ ಹರಿವು**: ಸುಗಮ ಪರಿವರ್ತನೆ ಮತ್ತು ಬಳಕೆದಾರ-ಸ್ನೇಹಿ ಅನುಭವ

#### ಹೇಗೆ ಬಳಸುವುದು:

1. **ಕನಿಷ್ಠ ಅವಶ್ಯಕತೆ**: ಕನಿಷ್ಠ 4 ಲರ್ನರ್‌ಗಳು ಅಗತ್ಯ
2. **AI ಮೋಡ್ ಸಕ್ರಿಯಗೊಳಿಸಿ**: Dialogue ಪುಟದಲ್ಲಿ "AI Group Mode" ಬಟನ್ ಕ್ಲಿಕ್ ಮಾಡಿ
3. **ಸ್ವಯಂಚಾಲಿತ ಪ್ರಾರಂಭ**: ಸಿಸ್ಟಮ್ ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಮೊದಲ ಗುಂಪನ್ನು ಆಯ್ಕೆ ಮಾಡುತ್ತದೆ
4. **ಸಂಭಾಷಣೆ ಆನಂದಿಸಿ**: ಸಿಸ್ಟಮ್ ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಎಲ್ಲವನ್ನೂ ನಿರ್ವಹಿಸುತ್ತದೆ

#### ಸಿಸ್ಟಮ್ ಹರಿವು:

```
ಪ್ರಾರಂಭ → ಗುಂಪು 1 (4 ಜನ) → 4 ರೌಂಡ್‌ಗಳು → ಗುಂಪು 2 (ಹೊಸ 4 ಜನ) → 4 ರೌಂಡ್‌ಗಳು → ...
```

#### ಪ್ರಯೋಜನಗಳು:

- **ಸಮಾನ ಭಾಗವಹಿಸುವಿಕೆ**: ಎಲ್ಲಾ ಲರ್ನರ್‌ಗಳಿಗೆ ಸಮಾನ ಅವಕಾಶ
- **ವೈವಿಧ್ಯತೆ**: ವಿವಿಧ ಗುಂಪು ಸಂಯೋಜನೆಗಳು
- **ಸ್ವಯಂಚಾಲಿತ**: ಯಾವುದೇ ಹಸ್ತಚಾಲಿತ ಹಸ್ತಕ್ಷೇಪ ಅಗತ್ಯವಿಲ್ಲ
- **ನಿರಂತರ ಕಲಿಕೆ**: ಅಡಚಣೆಯಿಲ್ಲದ ಭಾಷಾ ಅಭ್ಯಾಸ

## ತಾಂತ್ರಿಕ ವಿವರಗಳು (Technical Details)

### ಫೈಲ್‌ಗಳು:
- `ai-group-conversation.js` - ಮುಖ್ಯ AI ಗುಂಪು ನಿರ್ವಾಹಕ
- `dialogue.js` - AI ಮೋಡ್ ಏಕೀಕರಣ
- `dialogue.css` - AI UI ಶೈಲಿಗಳು
- `index.html` - AI ಮೋಡ್ UI ಅಂಶಗಳು

### ಮುಖ್ಯ ವರ್ಗಗಳು:
- `AIGroupConversationManager` - ಗುಂಪು ಆಯ್ಕೆ ಮತ್ತು ರೌಂಡ್ ನಿರ್ವಹಣೆ
- `DialoguePage` - AI ಮೋಡ್ ಏಕೀಕರಣ ಮತ್ತು UI ನಿಯಂತ್ರಣ

### ಕಾರ್ಯಚಟುವಟಿಕೆಗಳು:
- ಯಾದೃಚ್ಛಿಕ ಗುಂಪು ಆಯ್ಕೆ
- ಗುಂಪು ಇತಿಹಾಸ ಟ್ರ್ಯಾಕಿಂಗ್
- ರೌಂಡ್ ಪೂರ್ಣಗೊಳಿಸುವಿಕೆ ಪತ್ತೆ
- ಸ್ವಯಂಚಾಲಿತ ಪರಿವರ್ತನೆಗಳು
- ಅಂಕಿಅಂಶಗಳ ಟ್ರ್ಯಾಕಿಂಗ್

## ಬಳಕೆಯ ಉದಾಹರಣೆ (Usage Example)

```javascript
// AI ಮೋಡ್ ಪ್ರಾರಂಭಿಸಿ
dialoguePage.toggleAIMode();

// ಅಂಕಿಅಂಶಗಳನ್ನು ವೀಕ್ಷಿಸಿ
const stats = dialoguePage.getAIStatistics();
console.log('ಒಟ್ಟು ಸಂಭಾಷಣೆಗಳು:', stats.totalConversations);
console.log('ಅನನ್ಯ ಗುಂಪುಗಳು:', stats.uniqueGroups);
```
